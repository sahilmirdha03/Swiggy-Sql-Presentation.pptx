# Swiggy Restaurant Delivery — SQL Case Study

## Project Overview
This project analyzes a restaurant delivery dataset using SQL to explore customer behavior, restaurant performance, order trends, revenue, and delivery partner activity.

## Tools Used
- SQL
- MySQL
- GitHub

## Project Scope
The project contains 13 SQL questions covering:
- Customer location and order behavior
- Restaurant ratings and revenue
- Order counts and peak ordering hours
- Delivery partner performance
- Customer spending patterns
- Comparisons between customer orders

## Project Files
- `Swiggy Sql Presentation.pptx` — Presentation containing the questions, SQL queries, results, and key insights.
- `Swiggy_SQL_Queries.sql` — Complete SQL query script.

## Key Insights
The presentation highlights top-rated restaurants, revenue leaders, customer order patterns, and delivery partner performance.
